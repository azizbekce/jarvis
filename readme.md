# 🤖 J.A.R.V.I.S. CE-21 (v2.1.1)
### Personal AI Assistant & Autonomous Computer Interface — Powered by MEHNATKASH GROUP (AZIZBEKCE)

A real-time voice and desktop AI assistant that can hear, see, understand, and control your computer. Built with PySide6 translucent glass HUD, Bionic Eye-Pupil Core, real-time Gemini Live voice interaction, and full device synchronization.

---

## ✨ Key Features in J.A.R.V.I.S. CE-21 v2.1.1

| Feature | Description |
|---|---|
| 🎙️ **Real-Time Voice & Chat** | Ultra-low latency multi-language voice conversation (`O'zbekcha`, `Русский`, `English`) with instant live transcript streaming |
| 👁️ **3D Bionic Eye-Pupil Core** | Interactive cursor-tracking and autonomous human-like gaze with minimized Floating Sun-Core mode |
| 🖥️ **Full Device Control** | Launch/close apps, control volume/brightness/media, automate WhatsApp/Telegram/Browser, and manage files |
| 🌦️ **Device Sync & Live Weather** | Automatic IP geolocation, day/night sky state, local timezone clock, and CPU/RAM/NET telemetry |
| 🟢 **Hybrid Matrix + Binary Rain** | Interactive cursor spotlight blending Matrix katakana and `1` / `0` binary streams |
| 🔒 **Permissions & Self-Close** | First-launch personal Gemini API setup, granular device permissions, and voice/UI self-termination |

---

## ⚡ Quick Start (From Source)

```powershell
pip install -r requirements.txt
playwright install chromium
python main.py
```

---

## 📦 Windows Installer Build (`v2.1.1`)

Run from PowerShell on 64-bit Windows with Python 3.12 and Inno Setup 6:

```powershell
.\packaging\build_windows.ps1
```

Produces:
- `dist\JARVIS\JARVIS.exe`
- `dist\JARVIS-Setup-2.1.1.exe`
